CromPOS: Sistema de Facturación
e Inventario Venezuela

Desarrollamos CromPOS para resolver la complejidad operativa del comercio venezolano. Es un sistema administrativo programado en entornos robustos que permite la gestión simultánea de divisas y moneda local sin descuadres contables.

  • Sincronización automática con la tasa oficial BCV.
  • Infraestructura Cloud escalable y copias de seguridad automatizadas.
  • Compatibilidad total con impresoras térmicas y periféricos POS.

API Pública REST (JSON)

API Pública Dólar BCV
para Desarrolladores

Aceleramos el desarrollo de integraciones financieras en el país ofreciendo una API REST pública, rápida y gratuita que devuelve la tasa oficial del Banco Central de Venezuela. Al lado izquierdo puedes ver la respuesta de nuestro servidor consultada en tiempo real.

Diseñada para integrarse en un instante: no requiere tokens de autenticación (API Keys) ni configuraciones complejas. Respuesta nativa JSON procesable directamente en PHP, JavaScript, Python, Java o C#.

Endpoints disponibles (HTTP GET):
https://datos.cromstudio.com.ve/tasa

Open Data & Movilidad Urbana

Open Transit Venezuela:
Rutas y Mapas Abiertos

Lideramos el proyecto de estructuración de los datos del transporte público de Venezuela. Transformamos rutas empíricas en datos legibles por máquina utilizando la Especificación General de Feeds de Tránsito (GTFS).

Alojado en repositorios open-source y mapeado cartográficamente en OpenStreetMap, este proyecto permite a la ciudadanía planificar viajes con exactitud y a los desarrolladores crear aplicaciones de movilidad inteligente.

Preservación Cultural Digital

CriolloWiki: Memoria
Histórica Regional

Crom Studio gestiona la infraestructura técnica y el despliegue de CriolloWiki, una enciclopedia digital colaborativa construida sobre el motor DokuWiki.

Este es un esfuerzo filantrópico orientado a documentar con rigor la historia, las instituciones, la cultura y el rico léxico local de las regiones. Nuestro objetivo es blindar el patrimonio cultural asegurando que el conocimiento esté indexado en buscadores y preservado para el futuro.
