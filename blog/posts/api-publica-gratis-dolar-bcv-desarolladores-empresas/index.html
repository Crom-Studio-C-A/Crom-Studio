Mantener los sistemas de facturación , tiendas en línea y plataformas de punto de venta actualizados con la tasa de cambio oficial es un desafío técnico constante para las empresas en Venezuela.

Para facilitar este proceso, en Crom Studio hemos liberado nuestra API pública del Dólar BCV, una interfaz de programación de aplicaciones (REST API) gratuita, rápida y diseñada para integrarse en cualquier proyecto de software en cuestión de minutos.

Esta herramienta de datos abiertos permite a desarrolladores y empresas consultar la tasa de cambio oficial del Banco Central de Venezuela (BCV) estructurada en formato JSON, ideal para automatizar cálculos multimoneda sin depender de procesos manuales.

API Pública y Gratuita del Dólar BCV (JSON) para Desarrolladores y Empresas

Si estás buscando una API del BCV en Venezuela, una API del dólar BCV, una API de tasa BCV en JSON o una forma sencilla de consultar el dólar oficial de Venezuela desde un programa, Crom Studio ofrece una API pública diseñada para ese propósito.

La API del Dólar BCV de Crom Studio permite consultar datos de tasas de cambio mediante peticiones HTTP GET y recibir una respuesta estructurada en JSON, sin necesidad de crear una cuenta ni utilizar una API Key.

Es una herramienta pensada para desarrolladores, empresas y proyectos que necesitan integrar la tasa de cambio de Venezuela en sistemas de facturación, puntos de venta, tiendas online, aplicaciones web, aplicaciones móviles, bots, automatizaciones y sistemas ERP como Odoo.

Importante: Crom Studio actúa como intermediario tecnológico para distribuir los datos de referencia. La fuente oficial de la tasa de cambio es el Banco Central de Venezuela (BCV).

¿Qué es una API del BCV?

Una API del BCV permite que un programa consulte automáticamente información relacionada con las tasas de cambio publicadas por el Banco Central de Venezuela, en lugar de que una persona tenga que consultar manualmente una página web y copiar los valores.

En el caso de Crom Studio, la información se presenta mediante una interfaz HTTP sencilla y una respuesta JSON que puede ser procesada prácticamente por cualquier lenguaje de programación.

Esto permite utilizar la tasa BCV en JSON directamente en aplicaciones y sistemas empresariales.

Endpoints de la API

Actualmente existen dos endpoints principales.

/tasa — Endpoint completo

El endpoint /tasa proporciona la información estructurada de las tasas disponibles junto con la fecha de vigencia y la fecha de actualización.

https://datos.cromstudio.com.ve/tasa

Ejemplo:

{
  "fuente": "BCV_DB",
  "fecha_valor": "Martes, 29 Septiembre 2026",
  "tasas": {
    "USD": 857.8876,
    "EUR": 974.71473336
  },
  "actualizado_el": "2026-09-28T17:42:10.434283-04:00"
}

/dolar — Endpoint simplificado

Si solamente necesitas el valor del dólar estadounidense:

https://datos.cromstudio.com.ve/dolar

Respuesta:

{
  "current": {
    "usd": 857.8876
  }
}

En resumen:

  • /tasa → endpoint completo, recomendado para aplicaciones que necesitan USD, EUR, fecha y metadatos.
  • /dolar → endpoint simplificado, recomendado cuando únicamente necesitas el valor actual del USD.

Diccionario de datos de /tasa

fuente

Identifica la fuente de referencia de las tasas almacenadas y distribuidas por Crom Studio.

El valor:

"fuente": "BCV_DB"

no significa que el servidor que responde la petición pertenezca al Banco Central de Venezuela.

BCV_DB identifica la base de datos o sistema interno utilizado por Crom Studio para almacenar y servir los datos de referencia del BCV.

fecha_valor

Indica la fecha oficial de vigencia asociada a la tasa.

tasas

Contiene las cotizaciones disponibles, por ejemplo:

"tasas": {
  "USD": 857.8876,
  "EUR": 974.71473336
}

actualizado_el

Indica cuándo se actualizó el registro en la infraestructura de Crom Studio. Utiliza ISO 8601:

"actualizado_el": "2026-09-28T17:42:10.434283-04:00"

¿De dónde salen los datos del BCV?

Crom Studio utiliza como referencia la información pública correspondiente a las tasas de cambio publicadas por el Banco Central de Venezuela.

El proceso de actualización incorpora esos valores a la infraestructura de datos de Crom Studio, donde son almacenados y posteriormente expuestos mediante los endpoints JSON.

La arquitectura separa dos conceptos:

  1. Fuente de referencia: Banco Central de Venezuela.
  2. Infraestructura de distribución: Crom Studio.

Por tanto, consultar:

https://datos.cromstudio.com.ve/tasa

no equivale a realizar una petición directamente a bcv.org.ve. La API de Crom Studio funciona como una capa de distribución de datos preparada para aplicaciones y desarrolladores.

Para operaciones contables, tributarias o contractuales, conviene verificar siempre el dato directamente con la publicación oficial del BCV.

Ejemplo de integración en JavaScript

fetch('https://datos.cromstudio.com.ve/tasa')
  .then(response => response.json())
  .then(data => {
    const tasaDolar = data.tasas.USD;
    const tasaEuro = data.tasas.EUR;
    const fecha = data.fecha_valor;

    console.log(`Tasa USD: Bs. ${tasaDolar}`);
    console.log(`Tasa EUR: Bs. ${tasaEuro}`);
    console.log(`Fecha: ${fecha}`);
  })
  .catch(error => {
    console.error('Error al obtener la tasa BCV:', error);
  });

Ejemplo utilizando /dolar

fetch('https://datos.cromstudio.com.ve/dolar')
  .then(response => response.json())
  .then(data => {
    console.log(`Dólar BCV: Bs. ${data.current.usd}`);
  })
  .catch(error => {
    console.error('Error al obtener el dólar BCV:', error);
  });

Ejemplo con Python

import requests

url = "https://datos.cromstudio.com.ve/tasa"

response = requests.get(url)
response.raise_for_status()

data = response.json()

print("Dólar BCV:", data["tasas"]["USD"])
print("Euro BCV:", data["tasas"]["EUR"])
print("Fecha:", data["fecha_valor"])

Ejemplo con PHP

<?php

$url = "https://datos.cromstudio.com.ve/tasa";

$response = file_get_contents($url);
$data = json_decode($response, true);

echo "Dólar BCV: Bs. " . $data["tasas"]["USD"];
echo PHP_EOL;
echo "Euro BCV: Bs. " . $data["tasas"]["EUR"];

Preguntas frecuentes

¿La API del dólar BCV de Crom Studio es gratuita?

Sí. Los endpoints públicos están disponibles gratuitamente.

¿Necesito registrarme?

No. Puedes realizar peticiones directamente a los endpoints públicos.

¿Necesito una API Key?

No para los endpoints públicos /tasa y /dolar.

¿Qué formato devuelve la API?

JSON.

¿La API funciona desde JavaScript en el navegador?

Sí. El acceso CORS está habilitado para permitir el consumo directo desde aplicaciones frontend.

¿Existe un rate limit?

Los endpoints públicos están disponibles sin un límite de peticiones establecido para el uso normal.

¿Cuál es la diferencia entre /tasa y /dolar?

/tasa proporciona una respuesta completa con tasas, fecha y metadatos.

/dolar proporciona una respuesta simplificada con el valor actual del USD.

¿Qué monedas proporciona /tasa?

Actualmente la respuesta incluye USD y EUR.

¿Puedo utilizar la API en PHP, Python o Node.js?

Sí. Cualquier lenguaje capaz de realizar solicitudes HTTP y procesar JSON puede consumirla.

¿Puedo utilizarla en una tienda online?

Sí. Puede integrarse en tiendas y sistemas de comercio electrónico para automatizar consultas de tasas de cambio.

¿La API es directamente del Banco Central de Venezuela?

No. Los servidores y la API son de Crom Studio. Los datos de referencia proceden de la información pública del BCV.

¿Puedo utilizar la API para facturación?

Sí, técnicamente puede integrarse en sistemas de facturación. Para operaciones con implicaciones contables, tributarias o contractuales, debe verificarse la tasa oficial directamente en la fuente correspondiente y aplicarse la normativa vigente.
